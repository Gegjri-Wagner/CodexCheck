# Telegram бот: Угроза БПЛА для города Чебоксар

Этот бот отвечает на любые входящие сообщения текстом:

> Угроза БПЛА для города Чебоксар.

## Запуск

1. Создайте бота у @BotFather и получите токен.
2. Установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install requests
```

3. Запустите бота:

```bash
export TELEGRAM_BOT_TOKEN="ваш_токен"
python bot.py
```

## Как работает

Бот использует long polling через метод `getUpdates` и отправляет фиксированное сообщение в ответ на каждое входящее сообщение.
